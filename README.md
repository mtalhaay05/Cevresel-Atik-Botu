# ♻️ Çevre & Atık Ayrıştırma Discord Botu

Bu proje, kullanıcılara evsel ve endüstriyel atıkların doğru şekilde nasıl ayrıştırılacağını öğreten, geri dönüşüm süreçleri ve çevre bilinci hakkında dinamik bilgi sağlayan interaktif bir Discord botudur.

Bot, Discord'un modern **Select Menu (Açılır Liste)** bileşenlerini kullanarak kullanıcı dostu bir arayüz sunar ve seçilen atık kategorisi hakkında Wikipedia REST API üzerinden güncel özet veriler çeker.

---

## ✨ Özellikler

* **İnteraktif Seçim Menüsü:** Kullanıcılar komut yazdıktan sonra açılır listeden atık kategorisini (Plastik, Cam, Pil/E-Atık, Kağıt, Organik) kolayca seçebilir.
* **Ayrıştırma Rehberi:** Her atık türü için doğru konteyner rengi, temizleme ve küçültme talimatları sunulur.
* **Dinamik Bilgi Çekme:** Wikipedia REST API entegrasyonu ile seçilen atık türünün çevreye etkisi ve geri dönüşüm süreci anlık olarak özetlenir.
* **Görsel Embed Kartları:** Bilgiler sade, okunabilir ve renk kodlu Discord Embed mesajları olarak iletilir.
* **Gelişmiş SSL Uyumluluğu:** Windows ve antivirüs kaynaklı yerel sertifika doğrulama kilitlenmelerini bypass eden optimize edilmiş soket katmanı.
